# 🎯 EventForce Management System (Salesforce Project)

## 📌 Project Overview
EventForce Management System is a Salesforce-based CRM solution designed to manage event planning operations efficiently.

It helps in:
- Client management  
- Event scheduling  
- Venue booking  
- Vendor coordination  
- Feedback management  

---

## ⚙️ Features
- Salesforce CRM Implementation  
- Apex Classes & Triggers  
- Flow Automation  
- Lightning App Development  
- Reports & Dashboards  

---

## 🛠️ Technologies Used
- Salesforce CRM  
- Apex Programming  
- Lightning App Builder  
- Salesforce Flows  
- SOQL & SOSL

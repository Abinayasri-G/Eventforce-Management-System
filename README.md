# 🎯 EventForce Management System (Salesforce Project)

## 📌 Project Overview
EventForce Management System is a Salesforce-based CRM solution designed to manage event planning operations efficiently.

It helps in:
- Client management
- Event scheduling
- Venue booking
- Vendor coordination
- Feedback management

## 🚀 Features
✔ Event & Client Management  
✔ Venue Reservation System  
✔ Vendor Coordination  
✔ Automated Event Reminders  
✔ Approval Process for Cancellation  
✔ Reports & Dashboards  

## 🛠️ Technologies Used
- Salesforce CRM
- Apex Classes & Triggers
- Flows & Automation
- Lightning App
- Reports & Dashboards
